【検証】
提供PDFの正答表から抽出した全60件と採点データが一致。問題画像60枚は切り出し済み画像と同一。
コード検証で0点・36点・60点の採点、誤答の再回答採点、初回レポートの保持、回答・理解チェック・用語の保存復元、他試験の保存キーとの分離を確認。
SVG図解60枚は画像に描画して目視確認。JS構文と相対ファイルリンクの存在を確認。
ブラウザ内の画面・操作確認は、プレビュー接続のタイムアウトとローカルHTML表示のセキュリティ制限のため未実施。

【図解・解説改訂版】
60問すべての図を設問別に再作成しました。汎用の比較表ではなく、数直線、構文木、クロック波形、メモリ配置、通信の経路、UML、工程ネットワーク、証明書の時間軸、在庫推移などを使っています。
各設問の解説手順に、図の具体的な値・矢印・境界の読み方を追加しました。
例：問2は加算と倍率で標準偏差が変わる理由、問13は装置への要求割当て、問42はクリティカルパス45日の算出、問57は発注量E−（X−S）の導出を図示。
既存の画面構成と学習記録の保存キーを維持しています。更新時はJSとassetsを含むフォルダ全体を置き換えてください。
