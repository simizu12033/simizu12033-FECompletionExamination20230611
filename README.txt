【検証】

コード検証で0点・36点・60点の採点、誤答の再回答採点、初回レポートの保持、回答・理解チェック・用語の保存復元、他試験の保存キーとの分離を確認。

ブラウザ内の画面・操作確認は、プレビュー接続のタイムアウトとローカルHTML表示のセキュリティ制限のため未実施。

【図解・解説改訂版】
60問すべての図を設問別に再作成しました。汎用の比較表ではなく、数直線、構文木、クロック波形、メモリ配置、通信の経路、UML、工程ネットワーク、証明書の時間軸、在庫推移などを使っています。
各設問の解説手順に、図の具体的な値・矢印・境界の読み方を追加しました。
例：問2は加算と倍率で標準偏差が変わる理由、問13は装置への要求割当て、問42はクリティカルパス45日の算出、問57は発注量E−（X−S）の導出を図示。
既存の画面構成と学習記録の保存キーを維持しています。更新時はJSとassetsを含むフォルダ全体を置き換えてください。

【全選択肢の解説付きカード版】
60問のカードそれぞれに、ア〜エ4選択肢、合計240件の解説を追加しました。
カードをめくると、用語や記述の要点・意味・正答との違いを表示します。計算問題にも各選択肢の判断理由を用意しています。
カード60枚のIDと記録の保存キーは維持しているため、既存の学習記録を引き継ぎます。
原問題との再照合により、問4（3乗に比例する計算時間）、問8（1秒間の万命令数）、問11（アクセス透過性）、問30（リスク回避）、問49（垂直統合）、問52（ファウンドリ）の既存解説・図を修正しました。
問5の深さは原問題の「枝の数」に合わせて説明しています。
追加検証：全60カードに4選択肢があり、正答マークが正答表と一致。カード表面では選択肢解説を隠し、裏面では4件を表示。問題リンク、文字のエスケープ、採点・再回答・保存復元をコードで確認しました。ブラウザの実画面での操作確認は未実施です。

【問33の独立用語カード】
XSS、CSRF、セッションハイジャックの独立カードを追加し、用語カードは63枚になりました。各カードに意味・具体例・対策・問33の誤った対策との違い・OWASP参照を記載。問33のSQLインジェクションカードから各カードへ移動できます。用語検索にも対応します。既存カードのIDと保存キーを維持しました。

【本番への応用を目指す用語拡張版】
全60問の正答以外の選択肢も見直し、113カードを追加。合計176カードとなりました。各追加カードに意味、具体例、類似概念との違い、理解確認と答えを記載しています。
問35のオーバーライド、カプセル化、多相性は独立したカードと図を用意しました。オーバーロードとの区別も学べます。
検索欄を表示し、分野別フィルタと一覧からのカード選択を追加。各設問の基本カードから関連用語へ移動できます。
全60問の見直し結果はterm-coverage.htmlをご覧ください。数字・式のみの誤答は元の選択肢比較で扱っています。
既存カードのIDと保存キーを維持しました。学習済みの記録は残り、新しく追加したカードは未評価で始まります。
正答以外の用語も学べるように拡張していますが、この過去問を起点とする教材です。現行試験範囲全体の網羅や合格・出題の保証を示すものではありません。範囲の確認先としてIPAの公式シラバスを案内しています。
